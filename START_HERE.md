# 🚀 START HERE

## First Time Setup (5 minutes)

### 1️⃣ Install Dependencies
```bash
# Install frontend
npm install

# Install backend
cd backend
pip install -r requirements_api.txt
cd ..
```

### 2️⃣ Test Backend
```bash
cd backend
python test_backend.py
```

✅ If you see "All tests passed!", you're ready!

---

## 🎯 Run Your Portfolio

### Easiest Way:
Double-click `start_portfolio.bat` or run:
```bash
./start_portfolio.ps1
```

### Manual Way:
```bash
# Terminal 1 - Backend
cd backend
python flask_api.py

# Terminal 2 - Frontend  
npm run dev
```
