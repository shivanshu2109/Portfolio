## 1. Samtek - Software Engineer (AI Intern)

**Duration:** June 2024 - August 2024  
**Location:** Virginia, USA  
**Position:** Software Engineer - AI Intern

### Project: Cloud Converter Calculator

#### What the Project Was About
The Cloud Converter Calculator helps Samtek's clients evaluate the cost and feasibility of migrating their applications from a source cloud service to a target cloud service. Additionally, it allows clients to check the pricing of cloud services if they want to deploy their applications on a specific cloud platform.

#### My Role
I worked as an AI Intern, responsible for implementing the cloud service YAML conversion pipeline. My role involved developing an automated conversion system using Large Language Models (LLMs) that transforms a source cloud service YAML file into a target cloud YAML file, with efficiency and accuracy checks.

#### My Approach

**Three Key Steps:**

1. **LLM-based Conversion:**
   - Created a prompt for the LLM (via company-provided API)
   - Converted source YAML configuration to target cloud YAML
   - Leveraged natural language understanding for semantic conversion

2. **Caching System:**
   - Implemented a caching mechanism to store previously converted configurations
   - Reduced redundant API calls significantly
   - Improved efficiency and reduced operational costs

3. **Validation Layer:**
   - Added validation step by passing output YAML back to LLM with validation prompt
   - LLM verified if conversion was accurate
   - Flagged errors for manual review when necessary

#### Results & Impact
- ✅ **Reduced API calls significantly** through intelligent caching
- ✅ **Increased reliability** with automated validation ensuring correct cloud YAML conversion
- ✅ **Provided scalable solution** that clients can use for cloud migration cost estimation and configuration assessment
- ✅ Enabled clients to make informed decisions about multi-cloud strategies

#### Technologies Used
- Large Language Models (LLMs)
- YAML configuration management
- Python
- API integration
- Caching systems
- Validation frameworks
